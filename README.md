# SIDE A · 私人唱片博物馆

收藏你喜欢的音乐，把你的品味变成看得见的作品。

数据模型：Collection → Record → Memory → Share，全部保存在浏览器 IndexedDB（数据与备份页可导出/导入）。

## 功能
一级导航只有五个：唱片架、小屋、歌词、档案、名片。大厅即品牌入口，数据与备份收在右上角图标里。

| 模块 | 路由 | 内容 |
| --- | --- | --- |
| 大厅 | `#/` | 3D 唱片旋转木马、一句话录入、今日回顾、五个入口的便当格 |
| 录入 + 出场仪式 | `#/add` | 一句话解析，Apple Music 目录匹配封面，收藏时刻精确到秒，Three.js 开幕仪式 |
| 唱片架 | `#/shelf` | 格子柜：每个分组一格，不满一格时整排斜靠；悬停沿倾角抽出，点击展示 / Timeline / Galaxy / Notes |
| 唱片页 | `#/record/:id` | 记忆、循环、A/B 面；随机生成分享图（9 种版式族 + 6 种经典版式，3:4 / 9:16 / 1:1） |
| 小屋 | `#/house` | Three.js 剖面小屋：墙面、地面、时间、家具、挂画可布置并自动保存；点唱片放上唱机，进入沉浸聆听（30 秒试听，记忆作为字幕） |
| 歌词解剖室 | `#/lyrics` | iTunes 曲目表 + LRCLIB 歌词（带时间轴），在歌词里点选最多 4 行，7 种版式 + 随机艺术指导 |
| 品味档案 | `#/report` | 时间段可精确到秒；时间账本、星期 × 小时热力图、最晚一次、最长空白；长图与 12 秒竖屏短片 |
| 名片与交换 | `#/card` | 随机生成的品味名片、三步交换入坑专辑、收到的唱片、主题展览 |
| 数据与备份 | `#/lab` | 记录转化率、分享生成率、分享发布率、30 天留存；导入导出 |
| 访客 | `#/visit/…` `#/gift/…` | 展墙 / 3D 唱片架 / 走进 TA 的小屋；唱片卡信封开箱，可收进自己的唱片架 |

## 运行
```
npm install
npm run dev        # 开发
npx vite build --outDir release && npx vite preview --outDir release   # 生产
```
